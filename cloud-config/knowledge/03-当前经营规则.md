# 园丁经营事实 · economy V3

本文解释静态经营规则，不证明当前库存、设施、动物或事件状态。当前结果以设备实时查询为准，提案必须由玩家明确批准才执行：可点设备确认卡，也可在费用已说明后，通过下一轮明确语音确认并调用批准工具。两种方式走同一条本地提交路径。

四作物：轨光花、雨窝苔、缝甲藤、旅粮豆。五资源：水、能源、藤纤维、食物、旧零件。开局水16能源12零件2，三槽；普通容量水/能源/纤维60、食物30、零件20。本版按新游戏开始；产出遵守容量。

每轮10分钟。苔能源1产水6；花水2产能源5；藤水2能源1产纤维3；豆水2能源1产食物2。数字为平原普通产出；地区和照料装置会影响结果，以实时region_yield、locked_yield为准，成熟后产量锁定。每个有普通工作的10分钟周期收取园丁能源1，不按动作重复收取。

八设施：[0]储水池水4藤9零件1，120秒，水容量100；[1]集雨器藤6零件1，120秒，每10分钟水1；[2]集能板藤12零件2，180秒，每10分钟能源1；[3]蓄能箱能源4藤9零件1，120秒，能源容量100；[4]第四种植位水4藤9零件1，120秒；[5]工作台藤9零件1，180秒；[6]照料装置藤12零件2，180秒，指定一槽苔/藤/豆每轮能源多1产量多1，可关闭；[7]动物住所水4藤6零件1，120秒，必须繁茂树冠，容纳一鸟一鼠。竣工前不产生效果。

树苗到成树水4藤3，60秒；成树到繁茂树冠水6藤6，120秒。成树可以看见小鸟来访，不等于救助或帮助；繁茂树冠允许建设住所。大树不直接产资源，不占种植位。

地区每30分钟轮换：平原、荒原、旧城、隧道、森林。按花/苔/藤/豆排列，产量为5/6/3/2，6/4/2/2，4/8/3/2，4/4/2/2，5/7/4/3。集雨器在进入雨中旧城时额外水6，每次入场只一次。

寻雨雀救助食物2水2，60秒；每30分钟食物2水1；成功照料且有集雨器才水3，旧城再加2。拾荒鼠在鸟已入住后开放，救助食物4水2，60秒；每30分钟食物3水1；帮助有效期间每2次设备探索额外回收物1。动物无粮不扣费、不帮助、不死亡、不追账。入住后第一次成功30分钟照料才有帮助。

旅途是待决定的机会，接听不等于批准。设备探索能源2、120秒得回收物1，不直接得零件。水补给60秒水4；食物补给60秒食物2。无工作台也可手动拆解，回收物1、180秒得零件1，无额外能源费但普通工作需要有能源；有工作台时回收物1能源2、60秒得零件2。零件需求尚未满足时后续会继续提供设备机会，不能说一次探索足够建齐所有设施。

断电时普通工程暂停且保留进度。符合条件时应急取水300秒、水2，免费，完成后冷却30分钟。已有能源恢复来源时优先等其恢复。无轨光花可恢复时，未投入的停产槽可经玩家批准立即换成轨光花；已投入作物不偷偷删除，必要时低功耗收获释放槽位。提案仍需玩家明确批准。动物不会死亡。

四方向是优先级，不是自动花钱的任务队列；每项建设/探索/改种另行批准。通讯提示、接听和批准是三个不同步骤；有未读不等于已接听，已接听不等于已批准。施工与完成以设备真实状态为准。

补充恢复边界：已有集能板但没有雨窝苔、水不足2且能源已恢复时，允许玩家批准将未投入的停产槽立即改种雨窝苔（能源1），避免仅恢复能源却无法获得水。仍不覆盖已付费作物，也不自动改种。
