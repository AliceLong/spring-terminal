# 园丁悬浮 MVP 动画素材 · 本地首版

入口：../robot-hover-preview.html；经营预览已增加入口。48张透明PNG帧，12组、每组4帧；4张母版位于masters/。内置image_gen制作，完整提示词见generation-prompts.md。保留橙白机身、黑面板青色眼睛、圆形侧耳、玻璃罩嫩芽和机械肢。

|素材组|动作|复用|
|---|---|---|
|hover|收腿悬浮、眨眼|待机与前往目标|
|takeoff|支撑展开→机械肢收起|反向播放为降落|
|rest|落地闭眼、嫩芽轻垂|休息|
|tend|伸肢、摘叶、收回|整理与收获|
|water|持壶、倾倒、短水流、收回|浇水|
|build|扳手操作、检查|建设/维修|
|listen|专注、面向玩家|聆听|
|wait（历史素材）|不再单独播放|等待回复复用listen|
|speak|眼睛变化与机械肢手势|说话|
|recover|偏斜→回稳|轻晃回应之一|
|squint|眯眼、嫩芽摆动|轻晃回应之二|
|wave|抬肢、开心挥手|轻晃回应之三、等待接听、完成庆祝|

每帧160×176，统一黑面板中心锚点(80,72)，每组机壳中位宽度56像素。tools/prepare-hover-robot-art.py用于图集裁切、缩放和锚点配准；不重新绘制角色。manifest.json保留源图格子、有效边界、散列和帧组；正式设备接入时可裁掉透明边距并保留锚点。contact-sheet.png是48帧检查表。

本地预览包含14种动作/复用方式，实际480×480场景与放大查看；起伏、阴影、中央巡游和升降由程序处理，避免为位移增加逐帧图。模拟轻晃按钮从3种回应中随机选择，避免连续相同，小回应1秒冷却，大动作6.5秒冷却。它不连接硬件IMU、真实语音、任务或资源结算。安静展示降低绘制频率；起降为循环演示，不代表设备状态机已接入。

验证：48帧均含透明通道，无有效像素碰到画布边界；面部锚点配准。使用同一网页脚本在本地Canvas引擎渲染全部14模式，检查轻晃冷却、低频与暂停；原经营预览21步、独立设备8种组合回归通过。review-*.png是静态检查图，不是设备截图或浏览器自动验收。

独立帧PNG合计778584字节，这是本地文件大小，不是固件Flash或运行内存占用。母版保留高分辨率；本节为母版首版记录；设备接入与最新烧录状态以项目docs/gardener-gentle-response-20261021.md为准。接入设备前还需压缩编码和实机性能验证，既有发热问题没有因此解决。


## 缩小帧修正 · 第二版

首版深色区域识别把部分机械肢误判为脸，并逐帧缩放，造成突然缩小。现改为蓝黑色面板材质识别、同组统一缩放，只对齐位置；清除相邻格子边缘残片。使用-v2.png文件名和版本化脚本，避免浏览器复用旧帧。tests/hover-art-test.py约束每组固定缩放、源面板比例和有效文件；48帧检查表及14模式静态预览已重建检查。未重新生成母版，未更新设备。


## 手感修正版

本地预览同步小回应650毫秒、大动作1.1秒；浇水/施工保持工具与帧时钟，休息先睁眼再起飞。1秒小回应冷却独立于6.5秒大动作冷却。实际设备保留原IMU检测门槛和唤醒保护，没有发布低阈值判定。设备版已编译、烧录并正常启动，真实手感仍待短测。

## 接收信号与体型统一 · 第三版

聆听和等待回复统一listen；说话保持speak。接收信号由向内依次点亮的弧线表示，说话增加小喇叭及向外声波，无状态文字气泡。重新以橙白机壳宽度校准各动作组，浇水/施工不再比悬浮明显放大；同组仍固定缩放，采用-v3.png文件避免旧缓存。源素材48帧，设备仅使用44帧，等待组不再打包。上版浇水防打断已获用户实机确认。新视觉效果仍需实机观察。

## 持续浇灌 · 0.3.3

正常模式真实照料任务10秒，包含前往目标的时间；到位后拿壶800毫秒、倾倒700毫秒，中间保持浇灌，第10秒前最后1秒收壶。持续浇灌的长度随移动距离变化，普通帧不会反复播放拿起和收回动作。本地预览为到位状态的10秒循环演示，不含移动耗时。演示模式仍沿用加速逻辑。资源成本与经济结算保持原规则，晃动防打断保持。

## 升降巡游 · 0.3.4

前往目标预览增加上下弧线运动，阴影随高度变化。设备控制器采用两轴平滑速度，工作时接近目标后停稳；语音在当前高度悬停。巡游仅影响表现，不修改资源或任务。
