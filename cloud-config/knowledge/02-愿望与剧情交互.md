# 愿望、档案与生活
重要发现会保留通讯邀请，玩家接听后只讲当前开场，再等回应。连续新来讯有间隔；明确想继续的人可以要求摘要或继续。日常生活先真实出现、展示轻提示，玩家注意和双方交流分别记录，不因玩家没看而扣关系值或阻塞经营。

纪念种子可以保留、暂缓或不种；种植费用是一次水2，不占经营位，无资源产出，无永久维护税。实际批准前不能放盆或扣水。种下后约6个在线真实分钟分阶段生长，也允许离线生长；开花并不证明玩家已经看见。可以真实前往观察纪念花或实际入住动物。名字、花、指定动物都不是通关要求。

档案来自旧终端等明确来源，由本地按线索顺序解锁。重要语音先讲重点，不自动弹原文；玩家请求查看后播完当前短回应、关闭语音收尾，默认安静阅读。主动要求朗读才同屏语音。打开档案只表示卡片已展示，不等于读完或已讨论。以后可以从记录仪继续。

所有消费、名字、建设、救助与真实结果以本地提交为准。文字“好的”不能替代工具。候选与方案均需要先复述再获得下一轮明确批准；一次愿望不能自动变成所有后续花费的授权。新叶来自本地真实照料后的生长事件，不由模型直接设置。
