# 从本提交源码构建的配套固件

本目录由本次提交副本重新构建生成，包含 app、引导程序、分区表、初始 OTA 状态以及字体/声音等配套资源。未复制 NVS、Wi-Fi、设备身份或玩家进度。`manifest.json` 保存各镜像偏移和 SHA-256。

适用：Waveshare ESP32-S3-Touch-AMOLED-2.16、ESP32-S3、16 MB Flash，以及本包 V4.6 分区。新板需自行配网与绑定服务。此目录的全量写入示例适用于空白板或已另行备份并决定重新安装的板子，不能把它当作已有正式存档的通用无损升级。

激活 ESP-IDF 后，在本目录运行以下命令才会真正刷写；本次打包没有执行它：

```sh
python -m esptool --chip esp32s3 --port PORT write-flash @flash_args
```

把 PORT 换成实际串口。刷写前停止占用串口的终端。已有正确分区与资源的设备可由开发者按其部署方案只更新 app，但先核对分区、资源版本与完整备份。
