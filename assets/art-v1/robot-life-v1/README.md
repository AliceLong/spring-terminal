# 园丁自主生活动画 · 素材首版

2026-10-22。内置 image_gen 生成，沿用原机器人母版的橙白机身、玻璃罩嫩芽、机械肢和手绘风格。完整提示词见 [generation-prompts.md](generation-prompts.md)。

入口：[本地动画预览](preview.html)。可暂停、逐帧查看、调整节奏、对照原悬浮动作，以及切换设备16色编码效果。

- `masters/`：两张透明原画，每张2×2四帧。

- `device/`：独立I4编码文件和量化预览PNG，沿用现有设备.98缩放、alpha裁边和BGRA调色板约定；共30308字节，约29.6KiB。尚未加入固件素材表。
- `watch_window.webp`、`inspect_plant.webp`：透明动画，分别2.6秒和2秒循环。
- `contact-sheet.png`：8帧总览。
- `review-*.png`：当前车厢的场景示意，包含PNG与设备量化效果。检查植物的摆放用于观察伸手方向，不代表设备当前LifeX已调整。
- `manifest.json`、`catalog.js`：源文件、裁切、偏移、固定缩放及哈希信息。

## 校准与检查

使用 tools/prepare-life-robot-art.py 可重复拆帧与编码。每个动作组共用一个缩放值，通过橙白机壳定位对齐现有hover_0-v3；没有逐帧改变缩放。组内机壳投影宽度最大/最小约1.038和1.034，轻微差异来自姿态与绘画。透明边缘无裁切，8个I4文件均已逐像素解码对照。16种“动作×帧×编码模式”在本地Canvas完整绘制通过。

生成图并非骨骼动画，循环中的形体变化仍需要目测审阅；保留母版，便于后续针对单帧修正。

## 程序接入交接（本轮未改动固件）

当前 spring_gardener.h 的 WatchWindow 仍落入Hover默认映射；InspectPlant仍共用Tend。后续接入须新增两种Animation并映射对应Mode，按上述节奏循环；旧动画序号与原有偏移保持一致。现有 spring_art.cc 用“首帧Id + Animation序号×4 + 帧号”取图，新增资源必须同步检查枚举和数据排列，不能只复制PNG。

生活活动仍由LifeDirector的真实到位反馈与20现实秒停留判定，不用动画循环次数代替任务完成。前往、起降、休息、语音暂停和晃动回应沿用现有控制。检查夹爪朝画面右侧，需要让机器人停在目标植物左侧，或另行准备朝左素材；不能直接镜像带01字样的机身而产生反字。

本轮仅制作素材与本地预览：未修改游戏源码、设备存档或云端配置，未编译或烧录。PNG、母版和预览文件总体体积不等于设备Flash/RAM占用；实际设备预算应以接入后的构建为准。保持当前稳定屏幕传输路径。
