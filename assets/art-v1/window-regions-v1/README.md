# 窗外地区素材 v1

当前版本：window-near-slow-20261022，近景速度6像素/秒。远景使用平滑插值；近景使用160×48、64色精简图，取消插值，以480×128显示在y128位置。以下早期接入记录保留为历史。

原始素材与本地预览已完成；随后按用户要求导出精简设备素材并接入地区切换，应用已烧录，运行验证见 dist/window-regions-20261022/manifest.json。游戏数值、存档格式、显示驱动、设备分区与云端配置未修改。

## 地区与氛围

程序目前有五个地区。保留现有「晴朗平原」，新增四套远景与透明近景，共八张新原画。

整体保持安静、有生命力的末日后世界，不加入人物、战斗或灾难现场。车厢、窗框和机器人不烘焙进窗外图片。

## 预览

打开同目录 preview.html，可切换五个地区、暂停移动、关闭透明近景、切换设备编码效果，以及查看不同大树阶段和设施布置。

远景缓慢移动，近景速度较快；雨丝仅在雨中旧城作为独立效果显示。预览通过玻璃遮罩保留车窗框架与车厢。没有添加横向蓝色色带。

图片两端未经严格无缝绘制，预览采用交替镜像平铺，避免直接首尾拼接的明显跳变。这是高分辨率本地视觉方案；实际设备使用下文说明的精简包。

## 文件

- masters/：四套 AI 生成的原始远景和透明近景。
- layers/：含旧平原在内的五套标准尺寸素材；远景 480×240，透明近景 480×128。
- device/：远景 RGB565 和透明近景 I4 的候选文件，以及编码后的效果图。
- manifest.json：尺寸、格式、字节数和 SHA-256。
- overview.png：四个新增地区的远近景总览。
- review-*-png.png / review-*-device.png：放进 480×480 车厢后的检查图。
- generation-prompts.md：八张新原画的完整生成提示词。

生成使用内置 imagegen。尺寸整理与设备格式导出脚本位于 tools/prepare-window-regions-art.py。

## 检查结果

本地 Canvas 检查覆盖五个地区、两种图片编码和三个滚动位置，共 30 种组合。玻璃区域之外的车厢像素保持不变，五个地区的窗口画面均不同。I4 导出文件解码后与量化预览一致。

这些检查验证了本地合成与导出，不代表已经测得设备帧率、温度或实际内存峰值。

## 原始大尺寸候选包的限制

每套候选设备素材为 261,184 字节；四套新增共 1,044,736 字节，约 1 MiB。这是未压缩候选素材的存储量，不是运行时内存占用。

当前应用空间余量约 167 KB，不能直接把这四套全部作为新增应用内嵌资源。接入前需要另行确认素材分区、压缩或裁剪方案；本次没有调整分区。

原有设备背景已把窗外景色合进不透明车厢背景，不能只替换一张远景就自动完成地区切换。本次设备接入按玻璃区域合成远景和近景，同时保留已经验证稳定的显示路径。高分辨率预览近景为 480×128；设备精简版按同一场景坐标取样，不把候选原件直接加载到设备。


## 2026-10-22 设备接入

新增 firmware/ 精简包总计 49,408 字节，远景使用 128×64 I8，按双线性插值显示；透明近景使用 128×48 I4。原大尺寸 device/ 文件仍为候选原件，并未全部嵌入。

只在现有玻璃区域绘制，远景保持静止，近景镜像循环；正常每 500ms 更新，安静展示每 2000ms 更新，休眠沿用既有暂停逻辑。设备版不包含预览中的额外雨丝效果。现有单个 RGB565 画面条带扩大到 480×160，比原条带增加 67,200 字节；没有启用新的显示刷新或多缓冲机制。

窗外随真实游戏地区变化，不修改地区计时或强制切换存档。应用剩余空间约 17 KB，后续新增素材需重新规划存储。

## 近景位置修正

发现原近景范围 y185..313，加上素材顶部透明留白，导致大多数枝叶落到玻璃下方被裁掉。已把范围调整为 y145..257，本地预览同步。四地区窗内至少有15,804个半透明以上的近景像素，偏移后均有超过15,000个像素发生变化，已通过宿主实际渲染及设备编译。烧录状态以 dist/window-near-fix-20261022/manifest.json 为准。

## 车厢与近景前后关系修正

根据实机照片，原整块玻璃遮罩覆盖了烘焙在背景里的架子上半部分。现从架子原图的透明通道生成1,908字节遮挡掩码，在窗外合成时保留架子原像素，不覆盖横梁、立柱、附着植物。

近景更新为64色I6打包、预乘透明度双线性采样，显示宽720、高144、顶部118，速度12像素/秒。四个新地区的近景和遮挡数据共58,228字节。应用与原有资产分区不变。

实际LVGL渲染检查新增架子原像素保护断言，并验证四地区真实合成条带在相隔1秒后均有超过10,000字节发生变化，避免仅证明源图有像素。设备编码预览已切换到当前精简设备图。烧录状态见 dist/window-depth-fix-20261022/manifest.json。

## 近景清晰度修正

用户指出近景也被模糊化。已取消近景的预乘透明度双线性采样，只对远景保留插值；近景源图宽度128→160，显示宽度720→480，保持轮廓锐度。四套新素材与架子遮挡合计62,836字节。近景依然为12像素/秒，显示驱动和刷新节奏未更改。实际应用烧录结果见 dist/window-sharp-near-20261022/manifest.json。

## 近景速度调整

根据实机体验，把四个新地区的近景速度从12降至6像素/秒。保留近景清晰采样、远景平滑、架子遮挡和现有刷新节奏。本地车厢预览同步减速。
